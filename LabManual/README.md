# AI ペアプログラミング入門

Python で ToDo アプリを作成しながら、AI コーディングツールの基本を学ぶ 1 日間のコースです。

## セッション一覧

| セッション                | 内容                       |
| ------------------------- | -------------------------- |
| [Session 2](./session-2/) | 要件定義・設計支援         |
| [Session 3](./session-3/) | コード補完活用             |
| [Session 4](./session-4/) | レビュー・リファクタリング |
| [Session 5](./session-5/) | ドキュメント作成           |

## 事前準備

### 必要なソフトウェア

- **Python 3.10 以上**
- **VS Code** または **Cursor**
- **GitHub Copilot** または **Cursor の AI 機能**

### Python のバージョン確認

```sh
python --version
# または
python3 --version
```

## フォルダ構成

```txt
/
├── session-2/          # 要件定義・設計
│   ├── exercise/          # 要件定義・設計のテンプレート
│   └── Ans/
├── session-3/          # コード補完
│   ├── exercise/
│   └── Ans/
├── session-4/          # レビュー・リファクタリング
│   ├── exercise/
│   └── Ans/
└── session-5/          # ドキュメント作成
    ├── exercise/
    └── Ans/
```

## 進め方

1. 各セッションの `README.md` を読んで、手順を確認する
2. `exercise/` フォルダのコードを自分の作業フォルダにコピーする
3. AI コーディングツールを活用しながら、手順に沿って実装を進める
4. 困ったときは `README.md` のヒントを参考にする
