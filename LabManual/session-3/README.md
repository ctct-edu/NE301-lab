## 演習 1: メインメニューの実装（15 分）

この演習では、ToDo アプリのメインメニューを実装します。AI のインライン補完を活用しながら、コメントからコードを生成します。

### ステップ 1: ファイルを作成する

`todo.py` という名前で新しいファイルを作成します。

### ステップ 2: 骨格コードを入力する

以下のコードを入力します。

```py
# ToDo アプリのメインメニューを表示する

def main():
    # メニューを表示して、ユーザーの入力を受け付ける
    # 1-5 の選択肢に応じて処理を分岐する
    pass

if __name__ == "__main__":
    main()
```

- `if __name__ == "__main__":` は Python のお約束。このファイルを直接実行したときだけ `main()` が呼ばれる
- `pass` は「何もしない」という意味。後でコードに置き換える

### ステップ 3: AI の補完を活用して実装する

`pass` を削除し、コメントの下に新しい行を作成します。AI がインライン補完でコードを提案してくるので、内容を確認して `Tab` で受け入れます。

もし補完が出てこない場合は、以下のようにコメントを追加して誘導します：

```py
def main():
    # メニューを表示
    print("===== ToDo アプリ =====")
```

期待される実装の完成形：

```py
def main():
    while True:
        print("\n===== ToDo アプリ =====")
        print("1. タスク一覧を表示")
        print("2. タスクを追加")
        print("3. タスクを完了/未完了に切り替え")
        print("4. タスクを削除")
        print("5. 終了")
        print("======================")

        choice = input("選択してください (1-5): ")

        if choice == "5":
            print("終了します。")
            break
```

### ステップ 4: 動作確認

ターミナルで以下を実行します。

```sh
python todo.py
```

メニューが表示され、5 を入力すると終了することを確認します。

## 演習 2: タスク一覧表示の実装（15 分）

この演習では、タスクのデータ構造とタスク一覧を表示する関数を実装します。

### ステップ 1: テスト用のタスクデータを用意する

ファイルの先頭（`def main():` の前）に以下を追加します。

```py
# テスト用のタスクデータ
tasks = [
    {"id": 1, "title": "牛乳を買う", "completed": False, "created_at": "2024-01-15 10:30"},
    {"id": 2, "title": "メールを返信する", "completed": True, "created_at": "2024-01-14 09:00"},
]
```

これは Session 2 で設計したデータ構造です。`completed` が `True` なら完了済み、`False` なら未完了です。

### ステップ 2: 表示関数を実装する

`tasks` の下に以下のコードを追加します。

```py
def show_tasks(tasks):
    # タスク一覧を表示する
    # 完了状態は [x] または [ ] で表示
    pass
```

`pass` を削除し、AI の補完を活用して実装します。

期待される実装：

```py
def show_tasks(tasks):
    print("\n----- タスク一覧 -----")
    if not tasks:
        print("タスクがありません。")
        return
    for task in tasks:
        status = "[x]" if task["completed"] else "[ ]"
        print(f"{status} {task['id']}. {task['title']} ({task['created_at']})")
```

- `f"..."` は f-string。変数を `{}` で埋め込める
- 三項演算子 `[x] if completed else [ ]` で完了状態を切り替え

### ステップ 3: メインメニューから呼び出す

`main()` 関数内で、選択肢 1 のときに `show_tasks()` を呼び出すようにします。

```py
if choice == "1":
    show_tasks(tasks)
```

## 演習 3: タスク追加機能の実装（15 分）

この演習では、ユーザーからタスク名を入力してもらい、新しいタスクをリストに追加する機能を実装します。

### ステップ 1: datetime モジュールをインポートする

ファイルの先頭に以下を追加します。

```py
from datetime import datetime
```

`datetime` は日時を扱うための標準ライブラリです。タスクの作成日時を記録するために使用します。

### ステップ 2: 追加関数を実装する

以下のコードを追加します。

```py
def add_task(tasks):
    # ユーザーからタスク名を入力してもらう
    # 新しいタスクを作成してリストに追加する
    pass
```

AI の補完を活用して実装します。以下のポイントを含める必要があります：

1. ユーザーからタスク名を入力してもらう
2. 新しい ID を決定する（既存の最大 ID + 1）
3. 現在の日時を取得する
4. 新しいタスクを作成してリストに追加する

期待される実装：

```py
def add_task(tasks):
    title = input("タスク名を入力してください: ")

    # 新しい ID を決定
    if tasks:
        new_id = max(task["id"] for task in tasks) + 1
    else:
        new_id = 1

    # 現在の日時を取得
    created_at = datetime.now().strftime("%Y-%m-%d %H:%M")

    # 新しいタスクを作成
    new_task = {
        "id": new_id,
        "title": title,
        "completed": False,
        "created_at": created_at
    }

    tasks.append(new_task)
    print(f"タスク「{title}」を追加しました。")
```

- `max()` で既存タスクの最大 ID を取得
- `strftime()` で日時を指定したフォーマットの文字列に変換
- `tasks.append()` でリストに追加

### ステップ 3: メインメニューから呼び出す

```py
elif choice == "2":
    add_task(tasks)
```
