## この演習で使う AI 機能

この演習では、主に **インライン補完（コード補完）** を使います。コードを書いている途中で AI が続きを提案してくれる機能です。

| 操作           | 説明                                                                 |
| -------------- | -------------------------------------------------------------------- |
| 補完の表示     | コードを入力すると、薄いグレーの文字（ゴーストテキスト）で提案が表示 |
| `Tab`          | 提案を受け入れる                                                     |
| `Esc`          | 提案を拒否する                                                       |
| 次の候補を見る | GitHub Copilot: `Alt + ]` / Cursor: 自動で次の候補が表示             |

この機能は GitHub Copilot でも Cursor でも同じ操作です。

補完がうまく出てこない場合は、**コメントを書いて意図を伝える**のがコツです。AI はコメントを読んで、その内容に沿ったコードを提案してくれます。

> **注意**: このセッションでは Agent モードや Chat での実装はまだ行いません。インライン補完のみを使って実装を進めます。

## 演習 1: 自動補完機能の活用（10 分）

この演習では、AI のインライン補完機能を実際に使ってみます。`todo.py` のスケルトンコードを開き、コメントや関数名から AI がどのようにコードを提案してくるかを体験します。

### ステップ 1: ファイルを確認する

作業フォルダにコピーした `todo.py` を VS Code または Cursor で開きます。以下のような骨格コードが入っています。

```py
def main():
    """メイン関数。アプリケーションのエントリーポイント。"""
    # TODO: メニューを表示して、ユーザーの入力を受け付ける
    # TODO: 1-5 の選択肢に応じて処理を分岐する
    pass


if __name__ == "__main__":
    main()
```

- `if __name__ == "__main__":` は Python のお約束。このファイルを直接実行したときだけ `main()` が呼ばれます
- `pass` は「何もしない」という意味。後でコードに置き換えます

### ステップ 2: インライン補完を試してみる

使用する AI 機能: **インライン補完**

まずは簡単なコードで、インライン補完の使い方に慣れましょう。`main()` 関数の上に、以下のように関数名だけを入力してみてください。

```py
def greet():
```

関数名 `greet` から AI が中身を推測して、`print("Hello!")` のようなコードを提案してくるはずです。

- 提案が薄いグレーの文字（ゴーストテキスト）で表示されたら、内容を確認します
- 良い提案であれば `Tab` で受け入れます
- 意図と違う場合は `Esc` で拒否します

確認できたら、この `greet()` 関数は削除してかまいません。

### ステップ 3: コメントから補完を試す

次に、コメントを書いて AI に意図を伝えてみましょう。以下のように入力してみてください。

```py
# 1 から 10 までの合計を計算する
```

コメントの下で改行すると、AI がコメントの内容に沿ったコードを提案してくるはずです。`Tab` で受け入れてみてください。

このように、**コメントを先に書く → AI が提案 → 確認して受け入れ** という流れが、インライン補完の基本的な使い方です。

確認できたら、このコードも削除してかまいません。次の演習から、本格的に ToDo アプリの実装に入ります。

### ステップ 4: 表示関数を実装する

使用する AI 機能: **インライン補完**

`tasks` データの下に、以下の関数の骨格を入力します。

```py
def show_tasks(tasks):
    # タスク一覧を表示する
    # 完了状態は [x] または [ ] で表示
    pass
```

`pass` を削除し、コメントの下に新しい行を作ります。AI がインライン補完でコードを提案してくるので、内容を確認して `Tab` で受け入れます。

期待される実装：

```py
def show_tasks(tasks):
    if not tasks:
        print("タスクがありません。")
        return

    print("\n----- タスク一覧 -----")
    for task in tasks:
        status = "[x]" if task["completed"] else "[ ]"
        print(f"{status} {task['id']}. {task['title']} ({task['created_at']})")
    print("----------------------")
```

- `f"..."` は f-string（フォーマット文字列）。変数を `{}` で埋め込める書き方です
- `"[x]" if task["completed"] else "[ ]"` は三項演算子。`completed` が `True` なら `[x]`、`False` なら `[ ]` を返します

## 演習 3: タスク追加機能の実装（15 分）

この演習では、ユーザーからタスク名を入力してもらい、新しいタスクをリストに追加する機能を実装します。

### ステップ 1: datetime モジュールをインポートする

ファイルの先頭に以下を追加します。

```py
from datetime import datetime
```

`datetime` は日時を扱うための Python の標準ライブラリです。タスクの作成日時を記録するために使用します。

### ステップ 2: 追加関数の骨格を入力する

以下のコードを追加します。

```py
def add_task(tasks):
    # ユーザーからタスク名を入力してもらう
    # 新しいタスクを作成してリストに追加する
    pass
```

### ステップ 3: インライン補完で実装する

使用する AI 機能: **インライン補完**

`pass` を削除し、コメントの下で AI のインライン補完を活用して実装します。以下のポイントが含まれるように実装してください。

1. ユーザーからタスク名を入力してもらう（`input()` を使う）
2. 新しい ID を決定する（既存の最大 ID + 1）
3. 現在の日時を取得する
4. 新しいタスクを作成してリストに追加する

期待される実装：

```py
def add_task(tasks):
    title = input("タスク名を入力してください: ")

    if not title.strip():
        print("タスク名を入力してください。")
        return

    # 新しい ID を決定
    if tasks:
        new_id = max(task["id"] for task in tasks) + 1
    else:
        new_id = 1

    # 現在日時を取得
    created_at = datetime.now().strftime("%Y-%m-%d %H:%M")

    # 新しいタスクを作成
    new_task = {"id": new_id, "title": title.strip(), "completed": False, "created_at": created_at}

    tasks.append(new_task)
    print(f"タスク「{title.strip()}」を追加しました。")
```

- `max()` で既存タスクの最大 ID を取得しています
- `strftime()` で日時を `"2026-01-15 10:30"` のような文字列に変換しています
- `tasks.append()` でリストの末尾に新しいタスクを追加しています

### ステップ 4: メインメニューから呼び出す
