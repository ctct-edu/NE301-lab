# ToDo アプリ 設計書

## 1. データ設計

### 1.1 タスクのデータ構造

1 つのタスクは辞書（Dictionary）で表現する。

| フィールド名 | 型   | 説明                             | 例                   |
| ------------ | ---- | -------------------------------- | -------------------- |
| `id`         | int  | タスクを一意に識別するための番号 | `1`                  |
| `title`      | str  | タスクの内容                     | `"牛乳を買う"`       |
| `completed`  | bool | 完了したかどうか                 | `False`              |
| `created_at` | str  | 作成日時                         | `"2026-01-15 10:30"` |

```py
# タスクの例
task = {
    "id": 1,
    "title": "牛乳を買う",
    "completed": False,
    "created_at": "2026-01-15 10:30"
}
```

### 1.2 タスクリストの構造

複数のタスクは「辞書のリスト」で管理する。

```py
tasks = [
    {"id": 1, "title": "牛乳を買う", "completed": False, "created_at": "2026-01-15 10:30"},
    {"id": 2, "title": "メールを返信する", "completed": True, "created_at": "2026-01-14 09:00"},
]
```

### 1.3 デフォルト値

| フィールド   | デフォルト値 | 設定方法                                |
| ------------ | ------------ | --------------------------------------- |
| `id`         | 1            | 既存の最大 ID + 1（タスクがなければ 1） |
| `completed`  | `False`      | 新規作成時は必ず未完了                  |
| `created_at` | 現在日時     | `datetime.now().strftime()` で取得      |

## 2. ファイル設計

### 2.1 ファイル構成

```txt
todo_app/
├── todo.py      ... アプリケーション本体
└── tasks.csv    ... タスクデータ（自動生成）
```

### 2.2 CSV ファイル形式

```csv
id,title,completed,created_at
1,牛乳を買う,False,2026-01-15 10:30
2,メールを返信する,True,2026-01-14 09:00
```

## 3. 関数設計

### 3.1 関数一覧

| 関数名               | 引数   | 戻り値       | 説明                             |
| -------------------- | ------ | ------------ | -------------------------------- |
| `load_tasks()`       | なし   | `list[dict]` | CSV ファイルからタスクを読み込む |
| `save_tasks(tasks)`  | `list` | なし         | タスクを CSV ファイルに保存する  |
| `show_tasks(tasks)`  | `list` | なし         | タスク一覧を表示する             |
| `add_task(tasks)`    | `list` | なし         | 新しいタスクを追加する           |
| `toggle_task(tasks)` | `list` | なし         | タスクの完了状態を切り替える     |
| `delete_task(tasks)` | `list` | なし         | タスクを削除する                 |

### 3.2 処理フロー

```txt
1. アプリ起動
2. CSV ファイルからタスクを読み込む（load_tasks）
3. メニューを表示する
4. ユーザーの入力に応じて処理を実行する
5. データ変更時は CSV ファイルに保存する（save_tasks）
6. 「終了」が選ばれたらアプリを終了する
```

## 4. 使用モジュール

| モジュール | 用途                         |
| ---------- | ---------------------------- |
| `datetime` | タスクの作成日時を取得する   |
| `csv`      | CSV ファイルの読み書きを行う |
| `os`       | ファイルの存在確認を行う     |
