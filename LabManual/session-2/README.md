# Session 2: 要件定義・設計支援を体験

## 前提

Session 1 で AI コーディングツールの基本操作を学んでいること

---

## 演習 1: ToDo アプリの要件定義（20 分）

この演習では、AI と対話しながら ToDo アプリの要件を整理します。

### ステップ 1: テンプレートを開く

`templates/` フォルダにある `要件定義テンプレート.md` を VS Code または Cursor で開きます。

### ステップ 2: AI に機能の洗い出しを依頼する

チャットパネルを開き、以下のプロンプトを入力します。

**入力するプロンプト：**

```
コマンドラインで動作する ToDo アプリを作りたいです。
必要な機能を洗い出してください。
MUST（必須）と WANT（あれば良い）に分類してください。
```

AI の回答を確認します。以下のような分類が返ってくるはずです：

- **MUST**: タスクの追加、一覧表示、完了切り替え、削除など
- **WANT**: 期限設定、優先度、検索など

MUST は「この機能がないとアプリとして成立しない」もの、WANT は「あると便利だが、なくても最低限は動く」ものです。

### ステップ 3: 追加の質問をする

続けて以下のプロンプトを入力します。

**入力するプロンプト：**

```txt
ToDo アプリのタスク一覧表示では、どのような情報を表示すべきですか？
```

AI の回答を確認します。タスク ID、タスク名、完了状態、作成日時などが一般的です。

AI の提案をそのまま使うのではなく、自分のアプリに必要な情報を取捨選択することが重要です。

### ステップ 4: テンプレートに記入する

AI の回答を参考に、テンプレートの空欄を埋めます。

完成イメージ：

```txt
===== ToDo アプリ =====
1. タスク一覧を表示
2. タスクを追加
3. タスクを完了/未完了に切り替え
4. タスクを削除
5. 終了
======================
```

## 演習 2: ToDo アプリの設計（25 分）

この演習では、AI と対話しながらデータ構造と関数の設計を行います。

### ステップ 1: データ構造を AI に相談する

チャットパネルで以下のプロンプトを入力します。

**入力するプロンプト：**

```txt
ToDo アプリの 1 つのタスクには、どのような情報が必要ですか？
Python の辞書で表現する場合の例を示してください。
```

以下のような回答が期待されます：

```py
task = {
    "id": 1,
    "title": "牛乳を買う",
    "completed": False,
    "created_at": "2024-01-15 10:30"
}
```

各フィールドの意味：

| フィールド   | 説明                             |
| ------------ | -------------------------------- |
| `id`         | タスクを一意に識別するための番号 |
| `title`      | タスクの内容（文字列）           |
| `completed`  | 完了したかどうか（True/False）   |
| `created_at` | いつ作成されたか（日時の文字列） |

### ステップ 2: 関数の設計を AI に相談する

以下のプロンプトを入力します。

**入力するプロンプト：**

```txt
ToDo アプリに必要な関数を一覧にしてください。
各関数の引数と戻り値も含めてください。
```

以下のような関数が提案されるはずです：

| 関数名               | 説明                       |
| -------------------- | -------------------------- |
| `show_tasks(tasks)`  | タスク一覧を表示           |
| `add_task(tasks)`    | 新しいタスクを追加         |
| `toggle_task(tasks)` | タスクの完了状態を切り替え |
| `delete_task(tasks)` | タスクを削除               |

関数名は「何をするか」がわかる名前にすることが重要です。引数と戻り値を明確にしておくと、実装時に迷いません。

### ステップ 3: 設計テンプレートに記入する

`templates/` フォルダにある `設計テンプレート.md` を開き、AI の提案を参考にしながら埋めていきます。

すべて AI の提案通りにする必要はありません。自分のアプリに合わせてカスタマイズしてください。今回は最小限の機能（MUST）に絞って設計します。
