# Session 2: 要件定義・設計支援を体験

## 前提

Session 1 で AI コーディングツールの基本操作を学んでいること

## この演習で使う AI 機能

この演習では、AI と対話しながら要件や設計を整理するため、**チャット（Chat パネル）** を使用します。

チャットパネルの開き方は、お使いのツールによって異なります。

| ツール         | 操作                                                                                        |
| -------------- | ------------------------------------------------------------------------------------------- |
| GitHub Copilot | サイドバーのチャットアイコンをクリック、または `Ctrl + Shift + I`（Mac: `Cmd + Shift + I`） |
| Cursor         | `Ctrl + L`（Mac: `Cmd + L`）                                                                |

---

## 演習 1: ToDo アプリの要件定義（10 分）

この演習では、AI と対話しながら ToDo アプリの要件を整理し、要件定義書を完成させます。

### ステップ 1: テンプレートを開く

`exercise/` フォルダにある `要件定義テンプレート.md` を VS Code または Cursor で開きます。

> [!NOTE]
> **フォルダを VS Code で開くには**
>
> デスクトップにある該当フォルダを、デスクトップの VS Code のショートカットにドラッグ＆ドロップすると、そのフォルダが VS Code で開きます。

テンプレートの中身は空欄になっています。これを AI との対話を通じて埋めていきます。

### ステップ 2: チャットパネルを開く

チャットパネルを開きます。

- **GitHub Copilot**: サイドバーのチャットアイコンをクリック、または `Ctrl + Shift + I`（Mac: `Cmd + Shift + I`）
- **Cursor**: `Ctrl + L`（Mac: `Cmd + L`）

### ステップ 3: AI に機能の洗い出しを依頼する

チャットパネルに以下のプロンプトを入力して送信します。

**入力するプロンプト：**

```txt
コマンドラインで動作する ToDo アプリを作りたいです。
必要な機能を洗い出してください。
MUST（必須）と WANT（あれば良い）に分類してください。
```

AI の回答を確認します。以下のような分類が返ってくるはずです。

- **MUST**: タスクの追加、一覧表示、完了切り替え、削除など
- **WANT**: 期限設定、優先度、検索など

MUST は「この機能がないとアプリとして成立しない」もの、WANT は「あると便利だが、なくても最低限は動く」ものです。

### ステップ 4: 追加の質問をする

続けてチャットパネルに以下のプロンプトを入力して送信します。

**入力するプロンプト：**

```txt
ToDo アプリのタスク一覧表示では、どのような情報を表示すべきですか？
```

AI の回答を確認します。タスク ID、タスク名、完了状態、作成日時などが挙げられるはずです。

AI の提案をそのまま使うのではなく、自分のアプリに必要な情報を取捨選択することが重要です。

### ステップ 5: テンプレートに記入する

AI の回答を参考に、`要件定義テンプレート.md` の空欄を埋めます。以下の項目を記入してください。

1. **概要**: このアプリが何をするものか、1-2 文で記入
2. **MUST 機能**: タスクの追加、一覧表示、完了切り替え、削除、データ永続化
3. **WANT 機能**: 期限設定、優先度、検索など
4. **非機能要件**: 動作環境（Python 3.x）、データ保存形式（CSV）、外部ライブラリ（不要）
5. **ユーザーインターフェース**: メニュー画面のイメージ
6. **入出力仕様**: 各機能の入力と出力

完成イメージ（メニュー画面）：

```txt
===== ToDo アプリ =====
1. タスク一覧を表示
2. タスクを追加
3. タスクを完了/未完了に切り替え
4. タスクを削除
5. 終了
======================
選択してください (1-5):
```

完成イメージ（タスク一覧の表示形式）：

```txt
----- タスク一覧 -----
[ ] 1. 牛乳を買う (2026-01-15 10:30)
[x] 2. メールを返信する (2026-01-14 09:00)
----------------------
```

迷ったときは、チャットパネルで AI に追加の質問をしてみましょう。記入が終わったら、`Ans/` フォルダの完成例と見比べて確認してください。

## 演習 2: ToDo アプリの設計（15 分）

この演習では、AI と対話しながらデータ構造と関数の設計を行い、設計書を完成させます。

### ステップ 1: テンプレートを開く

`exercise/` フォルダにある `設計テンプレート.md` を開きます。

### ステップ 2: データ構造を AI に相談する

**チャットパネル** を開きます。

- **GitHub Copilot**: サイドバーのチャットアイコンをクリック、または `Ctrl + Shift + I`（Mac: `Cmd + Shift + I`）
- **Cursor**: `Ctrl + L`（Mac: `Cmd + L`）

チャットパネルに以下のプロンプトを入力して送信します。

**入力するプロンプト：**

```txt
ToDo アプリの 1 つのタスクには、どのような情報が必要ですか？
Python の辞書で表現する場合の例を示してください。
```

以下のような回答が期待されます。

```py
task = {
    "id": 1,
    "title": "牛乳を買う",
    "completed": False,
    "created_at": "2026-01-15 10:30"
}
```

各フィールドの意味を確認しましょう。

| フィールド   | 型   | 説明                             |
| ------------ | ---- | -------------------------------- |
| `id`         | int  | タスクを一意に識別するための番号 |
| `title`      | str  | タスクの内容（文字列）           |
| `completed`  | bool | 完了したかどうか（True/False）   |
| `created_at` | str  | いつ作成されたか（日時の文字列） |

### ステップ 3: 関数の設計を AI に相談する

続けてチャットパネルに以下のプロンプトを入力して送信します。

**入力するプロンプト：**

```txt
ToDo アプリに必要な関数を一覧にしてください。
各関数の引数と戻り値も含めてください。
```

以下のような関数が提案されるはずです。

| 関数名               | 引数   | 戻り値       | 説明                             |
| -------------------- | ------ | ------------ | -------------------------------- |
| `load_tasks()`       | なし   | `list[dict]` | CSV ファイルからタスクを読み込む |
| `save_tasks(tasks)`  | `list` | なし         | タスクを CSV ファイルに保存する  |
| `show_tasks(tasks)`  | `list` | なし         | タスク一覧を表示する             |
| `add_task(tasks)`    | `list` | なし         | 新しいタスクを追加する           |
| `toggle_task(tasks)` | `list` | なし         | タスクの完了状態を切り替える     |
| `delete_task(tasks)` | `list` | なし         | タスクを削除する                 |

関数名は「何をするか」がわかる名前にすることが重要です。引数と戻り値を明確にしておくと、実装時に迷いません。

### ステップ 4: 使用モジュールを AI に確認する

チャットパネルに以下のプロンプトを入力して送信します。

**入力するプロンプト：**

```txt
この ToDo アプリの実装で必要になる Python の標準ライブラリを教えてください。
```

以下のような回答が期待されます。

| モジュール | 用途                         |
| ---------- | ---------------------------- |
| `datetime` | タスクの作成日時を取得する   |
| `csv`      | CSV ファイルの読み書きを行う |
| `os`       | ファイルの存在確認を行う     |

### ステップ 5: 設計テンプレートに記入する

AI の提案を参考にしながら、`設計テンプレート.md` の空欄を埋めていきます。以下の項目を記入してください。

1. **データ設計**: タスクのデータ構造（フィールド名、型、説明、例）、タスクリストの構造、デフォルト値
2. **ファイル設計**: ファイル構成（`todo.py` と `tasks.csv`）、CSV ファイル形式
3. **関数設計**: 関数一覧（関数名、引数、戻り値、説明）、処理フロー
4. **使用モジュール**: 必要な Python の標準ライブラリ

すべて AI の提案通りにする必要はありません。自分のアプリに合わせてカスタマイズしてください。今回は最小限の機能（MUST）に絞って設計します。

記入が終わったら、`Ans/` フォルダの完成例と見比べて確認してください。
