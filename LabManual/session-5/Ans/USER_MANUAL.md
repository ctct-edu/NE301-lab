# ToDo アプリ ユーザーマニュアル

## アプリの起動方法

1. ターミナル（黒い画面）を開きます
2. `todo.py` があるフォルダに移動します
3. 以下のコマンドを入力して Enter を押します

```
python todo.py
```

メニュー画面が表示されたら起動成功です。

## 各機能の使い方

### タスクを一覧表示する

1. メニューで `1` を入力して Enter を押します
2. 登録されているタスクが表示されます

```
----- タスク一覧 -----
[ ] 1. 牛乳を買う (2026-01-15 10:30)
[x] 2. メールを返信する (2026-01-14 09:00)
----------------------
```

- `[ ]` がついているタスクはまだ完了していません
- `[x]` がついているタスクは完了済みです

タスクが 1 つも登録されていない場合は「タスクがありません。」と表示されます。

### タスクを追加する

1. メニューで `2` を入力して Enter を押します
2. 「タスク名を入力してください:」と表示されるので、タスクの内容を入力して Enter を押します
3. 「タスク「〇〇」を追加しました。」と表示されたら追加完了です

```
タスク名を入力してください: 資料を作成する
タスク「資料を作成する」を追加しました。
```

何も入力せずに Enter を押すと、エラーメッセージが表示されます。

### タスクの完了/未完了を切り替える

1. メニューで `3` を入力して Enter を押します
2. タスク一覧が表示されるので、切り替えたいタスクの番号を入力して Enter を押します
3. タスクの状態が切り替わります

```
切り替えるタスクの番号を入力してください: 1
タスク「牛乳を買う」を完了にしました。
```

もう一度同じタスクを選ぶと、未完了に戻ります。

### タスクを削除する

1. メニューで `4` を入力して Enter を押します
2. タスク一覧が表示されるので、削除したいタスクの番号を入力して Enter を押します
3. 確認メッセージが表示されるので、削除する場合は `y` を入力して Enter を押します

```
削除するタスクの番号を入力してください: 2
タスク「メールを返信する」を削除しますか？ (y/n): y
タスク「メールを返信する」を削除しました。
```

`n` を入力すると削除がキャンセルされます。

### アプリを終了する

メニューで `5` を入力して Enter を押すと、アプリが終了します。

## よくある質問（FAQ）

### Q. アプリを閉じたらタスクは消えますか？

A. いいえ、消えません。タスクは `tasks.csv` というファイルに自動保存されます。次回起動したときに、前回のタスクがそのまま表示されます。

### Q. 数字以外を入力したらどうなりますか？

A. メニューでは「無効な選択です」と表示されます。タスクの番号入力では「数字を入力してください」と表示されます。いずれの場合も、アプリが止まることはありませんので、正しい番号を入力し直してください。

### Q. タスク名に文字数の制限はありますか？

A. はい、100 文字以内で入力してください。100 文字を超えるとエラーメッセージが表示されます。

### Q. `tasks.csv` を直接編集しても大丈夫ですか？

A. 編集は可能ですが、フォーマットが崩れるとアプリが正しく動作しなくなる場合があります。通常はアプリから操作することをおすすめします。
