# ToDo アプリ

コマンドラインで動作するシンプルな ToDo 管理アプリケーションです。タスクの追加・表示・完了管理・削除ができ、データは CSV ファイルに保存されるため、アプリを終了してもタスクが保持されます。

## 機能一覧

| 機能                | 説明                                               |
| ------------------- | -------------------------------------------------- |
| タスク一覧表示      | 登録されたタスクを完了状態とともに一覧表示         |
| タスク追加          | 新しいタスクを登録（タスク名のバリデーション付き） |
| 完了/未完了切り替え | タスクの完了状態をトグルで切り替え                 |
| タスク削除          | 確認メッセージ付きでタスクを削除                   |
| CSV 保存            | タスクデータを CSV ファイルに自動保存・読み込み    |

## 必要な環境

- Python 3.x

外部ライブラリのインストールは不要です。Python の標準ライブラリのみを使用しています。

## 使い方

### 起動方法

```sh
python todo.py
```

### 操作方法

起動するとメニューが表示されます。1〜5 の数字を入力して操作を選択します。

```
===== ToDo アプリ =====
1. タスク一覧を表示
2. タスクを追加
3. タスクを完了/未完了に切り替え
4. タスクを削除
5. 終了
======================
選択してください (1-5):
```

### 出力例

タスク一覧の表示例：

```
----- タスク一覧 -----
[ ] 1. 牛乳を買う (2026-01-15 10:30)
[x] 2. メールを返信する (2026-01-14 09:00)
----------------------
```

- `[ ]` は未完了のタスク
- `[x]` は完了済みのタスク

## ファイル構成

```
todo.py      ... アプリケーション本体
tasks.csv    ... タスクデータ（自動生成）
```
