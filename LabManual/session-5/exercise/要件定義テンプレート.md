# ToDo アプリ 要件定義書

## 1. 概要

コマンドラインで動作するシンプルな ToDo 管理アプリケーション。タスクの追加・表示・完了管理・削除ができ、データは CSV ファイルに保存される。

## 2. 機能要件

### 2.1 MUST（必須機能）

| 機能                  | 説明                                              |
| --------------------- | ------------------------------------------------- |
| タスク一覧表示        | 登録されたタスクを完了状態とともに一覧表示する    |
| タスク追加            | 新しいタスクを登録する                            |
| タスク完了/未完了切替 | タスクの完了状態をトグルで切り替える              |
| タスク削除            | 確認メッセージを表示した上でタスクを削除する      |
| データ永続化          | タスクを CSV ファイルに保存し、再起動後も保持する |

### 2.2 WANT（オプション機能）

| 機能     | 説明                                 |
| -------- | ------------------------------------ |
| 期限設定 | タスクに期限日を設定する             |
| 優先度   | タスクに優先度（高/中/低）を設定する |
| 検索     | キーワードでタスクを検索する         |

## 3. 非機能要件

- **動作環境**: Python 3.x
- **データ保存形式**: CSV ファイル（tasks.csv）
- **外部ライブラリ**: 不要（標準ライブラリのみ使用）

## 4. ユーザーインターフェース

```txt
===== ToDo アプリ =====
1. タスク一覧を表示
2. タスクを追加
3. タスクを完了/未完了に切り替え
4. タスクを削除
5. 終了
======================
選択してください (1-5):
```

### 4.1 タスク一覧の表示形式

```txt
----- タスク一覧 -----
[ ] 1. 牛乳を買う (2026-01-15 10:30)
[x] 2. メールを返信する (2026-01-14 09:00)
----------------------
```

## 5. 入出力仕様

### 5.1 タスク追加

- **入力**: タスク名（文字列、100 文字以内）
- **出力**: 「タスク「〇〇」を追加しました。」
- **自動設定**: ID（既存の最大 ID + 1）、作成日時（現在日時）、完了状態（False）

### 5.2 完了/未完了の切り替え

- **入力**: タスク ID（数値）
- **出力**: 「タスク「〇〇」を完了/未完了にしました。」

### 5.3 タスク削除

- **入力**: タスク ID（数値）→ 確認（y/n）
- **出力**: 「タスク「〇〇」を削除しました。」または「削除をキャンセルしました。」
