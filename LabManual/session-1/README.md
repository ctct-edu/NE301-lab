# Session 1: AI コーディングツールの基本操作を体験する

## この演習で使う AI 機能

この演習では、3 つの AI 機能を順番に体験します。

| 機能           | 用途                                         | 操作                                                                                               |
| -------------- | -------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| インライン補完 | コードを書いている途中で AI が続きを自動提案 | コードを入力すると薄いグレーの文字で提案が表示。`Tab` で受け入れ、`Esc` で却下                     |
| インライン編集 | コードを選択して AI に編集を指示             | GitHub Copilot: `Ctrl + I`（Mac: `Cmd + I`）/ Cursor: `Ctrl + K`（Mac: `Cmd + K`）                 |
| チャット       | AI と対話形式で質問や相談をする              | GitHub Copilot: `Ctrl + Shift + I`（Mac: `Cmd + Shift + I`）/ Cursor: `Ctrl + L`（Mac: `Cmd + L`） |

---

## 演習 1: インライン補完を体験する

AI コーディングツールの最も基本的な機能である **インライン補完（自動補完）** を体験します。コードを書いている途中で、AI が続きを予測して薄いグレーの文字（ゴーストテキスト）で提案してくれる機能です。

### ステップ 1: Python ファイルを作成する

VS Code または Cursor で、新しいファイル `sample.py` を作成します。

> [!NOTE]
> VS Code は、演習用フォルダが開いた状態で起動する設定になっています。もし表示が異なる場合（フォルダが開かれていない場合）は、デスクトップにある該当フォルダを、デスクトップの VS Code のショートカットにドラッグ＆ドロップすると、そのフォルダが VS Code で開きます。

ファイルの作成方法:

1. エクスプローラー（左側のファイル一覧）で右クリック →「新しいファイル」
2. ファイル名を `sample.py` と入力して Enter

### ステップ 2: コメントを書いて補完を試す

使用する AI 機能: **インライン補完**

`sample.py` に以下のコメントを入力します。

```py
# 2つの数値を足し算する関数
```

コメントを入力した後、Enter キーで改行します。すると、AI がコメントの内容を読み取って、関数のコードを薄いグレーの文字で提案してくれるはずです。

提案が表示されたら、内容を確認して `Tab` キーで受け入れます。

以下のようなコードが提案されるはずです（AI の提案は毎回少し異なることがあります）。

```py
# 2つの数値を足し算する関数
def add(a, b):
    return a + b
```

- AI はコメントの内容を読み取って、それに合ったコードを提案してくれます
- 提案が意図と違う場合は、`Esc` で却下できます
- 提案が出てこない場合は、改行してから少し待ってみてください

完成したら、`Ans/sample_ex1.py` と見比べて確認してください。AI からの提案が出なかった場合は、このファイルの内容をコピーして次の演習に進んで構いません。

## 演習 2: インライン編集を体験する

**インライン編集** を体験します。コードを選択した状態で AI に自然言語で編集の指示を出せる機能です。インライン補完が「AI が自動で提案してくれる」のに対し、インライン編集は「自分から AI に指示を出す」点が異なります。

### ステップ 1: 修正したいコードを選択する

演習 1 で作成した `sample.py` を開きます。

`add` 関数全体（コメント行を含む）をマウスまたはキーボードで選択します。

```py
# 2つの数値を足し算する関数
def add(a, b):
    return a + b
```

### ステップ 2: インライン編集を起動する

使用する AI 機能: **インライン編集**

コードを選択した状態で、インライン編集を起動します。

- **GitHub Copilot**: `Ctrl + I`（Mac: `Cmd + I`）
- **Cursor**: `Ctrl + K`（Mac: `Cmd + K`）

エディタ上にプロンプト入力欄が表示されます。

### ステップ 3: AI に編集を指示する

表示されたプロンプト入力欄に、以下を入力して送信します。

**入力するプロンプト：**

```txt
引き算をする関数に変更してください。関数名も subtract に変更してください
```

AI が関数を書き換えた提案を表示します。変更内容を確認して、問題なければ「Accept」（受け入れ）をクリックします。

修正後のコードは以下のようになります。

```py
# 2つの数値を引き算する関数
def subtract(a, b):
    return a - b
```

ポイント：

- インライン補完は「AI が勝手に提案してくれる」機能ですが、インライン編集は「自分から指示を出す」機能です
- コードの一部分だけを選択して指示することで、ピンポイントな修正ができます
- 「Accept」で受け入れた後も、`Ctrl + Z`（Mac: `Cmd + Z`）で元に戻せます

完成したら、`Ans/sample_ex2.py` と見比べて確認してください。演習 3 ではこの状態の `sample.py` を使います。

## 演習 3: チャットで AI と対話する

**チャット（Chat パネル）** を使って AI と対話します。チャットは、コードについて質問したり、設計の相談をしたり、アイデアを出してもらったりと、幅広い用途で使える機能です。

ここでは、次の Session 2 以降で作っていく **ToDo アプリ** について、AI と対話しながら要件を整理していきます。

### ステップ 1: チャットパネルを開く

使用する AI 機能: **チャット（Chat パネル）**

- **GitHub Copilot**: サイドバーのチャットアイコンをクリック、または `Ctrl + Shift + I`（Mac: `Cmd + Shift + I`）
- **Cursor**: `Ctrl + L`（Mac: `Cmd + L`）

### ステップ 2: AI にコードを説明してもらう

まずは、演習 1 〜 2 で作った `sample.py` について AI に質問してみましょう。

チャットパネルに以下のプロンプトを入力して送信します。

**入力するプロンプト：**

```txt
@sample.py のコードを初心者にもわかるように説明してください。
```

`@sample.py` と入力すると、ファイルの内容を AI に渡すことができます。GitHub Copilot でも Cursor でも `@` でファイルを参照できます。

AI の回答を確認してみましょう。各関数の役割や Python の基本的な構文について、わかりやすく説明してくれるはずです。
